# 로그인·기록 저장 설정 가이드 (Firebase, 무료)

화면 글자는 조금 다를 수 있다. 막히면 화면을 캡처해서 보내 주세요.

## 0. 먼저: 새 파일을 GitHub에 올린다
이번 압축 파일의 내용을 저장소에 다시 올린다 (같은 이름은 덮어쓴다). 새로 생긴 것: `vendor/` 폴더, `js/cloud.js`, `js/merge.js`, `js/firebase-config.js`.
이 단계만 해도 앱은 정상 동작한다. 설정 화면의 로그인 칸에는 "준비 중이에요"가 보인다.

## 1. Firebase 프로젝트 만들기
1. https://console.firebase.google.com 에 구글 계정으로 로그인
2. **프로젝트 추가** → 이름 `passport-english` → 계속
3. Google 애널리틱스는 **끄기** → 프로젝트 만들기

## 2. 웹 앱 등록하고 연결 값 받기
1. 프로젝트 첫 화면에서 `</>` (웹) 아이콘 클릭
2. 앱 닉네임 `passport-english-web`, "Firebase Hosting" 체크는 **하지 않는다** → 앱 등록
3. `firebaseConfig` 가 나온다. 아래 4개 값을 메모장에 복사해 둔다: `apiKey`, `authDomain`, `projectId`, `appId`

## 3. 로그인 방식 켜기
1. 왼쪽 메뉴 **빌드 → Authentication → 시작하기**
2. **로그인 방법** 탭에서 **Google** → 사용 설정 → 프로젝트 지원 이메일 고르기 → 저장
3. 같은 탭에서 **이메일/비밀번호** → 사용 설정 (이메일 링크 아님) → 저장

## 4. 기록 저장소(데이터베이스) 만들기
1. **빌드 → Firestore Database → 데이터베이스 만들기**
2. 위치는 **asia-northeast3 (서울)** 권장, **프로덕션 모드**로 시작
3. 만든 뒤 **규칙** 탭을 열고 기존 내용을 지운 다음 `docs/firestore.rules` 내용을 붙여 넣고 **게시**

## 5. 연결 값 붙여 넣기
GitHub 저장소에서 `js/firebase-config.js` 를 열고 연필(편집) 아이콘 → 2단계에서 복사한 4개 값을 따옴표 안에 붙여 넣기 → **Commit changes**
(이 값은 비밀 키가 아니라 연결 주소표다. 공개 저장소에 있어도 된다.)

## 6. 내 사이트 주소 허용하기
**Authentication → 설정 → 승인된 도메인 → 도메인 추가** → `hs4808s-droid.github.io` 입력 → 추가
(저장소 주소가 다르면 그 주소의 도메인 부분만 쓴다.)

## 7. 확인
1~2분 뒤 사이트를 열고(새로고침 두세 번) **설정 → Google로 로그인**.
- 폰에서 공부 → 컴퓨터에서 같은 계정으로 로그인 → 같은 기록이 보이는지
- 컴퓨터에서 공부 → 폰 설정의 "지금 저장하기" → 기록이 따라오는지

## 문제가 생기면
설정 화면에 나오는 **오류 코드**를 알려 주세요.
- `auth/unauthorized-domain` → 6단계
- `auth/operation-not-allowed` → 3단계
- `permission-denied` → 4단계 규칙
- `failed-precondition` 또는 `not-found` → 4단계 데이터베이스 만들기
