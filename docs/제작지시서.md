# 패스포트 영어 — 제작 지시서

Claude Code에 넘기는 문서다. 이 문서와 폴더(`passport-english/`)만 있으면 이어서 만들 수 있게 썼다.
**역할 나눔: Opus = 설계·문장 작성·검수 / Sonnet = 구현·수정.**

## 1. 한 줄 목적
한국어를 보고 10초 안에 영어로 말할 수 있게, 소리 내어 연습하는 여행 영어 앱. 사용 시작 4주 뒤 30문장을 10초 안에 말하는 것이 성공 기준이다.

## 3. 지금 상태 (첫 빌드)
- 만든 것: 홈, 연습 모드 고르기, 기록(스탬프·배지·레벨), 설정, 수준 테스트, 학습 화면(복습·듣기·따라 말하기·영어로 말하기), 완료 축하 화면, 상황극, 쉐도잉·듣기.
- 설치형 웹앱: 홈 화면에 추가 가능, 인터넷 없이도 열림(음성 mp3 53개 포함 저장).
- 확인한 것(2026-11-23, 컴퓨터 크롬으로 확인): 1일차 완주(XP 135), 2일차 대기열(복습 5 + 새 문장 5), 7일차 마무리 복습 30문장, 오프라인 열림, mp3 53개 전부 재생 가능, 오류 0건.
- **확인 못 한 것: 실제 휴대폰(안드로이드·아이폰)에서의 동작.** 아래 6절 1번을 먼저 한다.

## 4. 폴더와 읽는 순서
```
passport-english/
  index.html            껍데기. 아래 스크립트를 순서대로 읽는다
  manifest.webmanifest  설치 정보(이름·아이콘·색)
  sw.js / precache.js   오프라인 저장. precache.js는 자동 생성
  css/app.css           모든 모양
  data/travel.js        문장 묶음(영어·한국어·팁·음성 경로). 문장은 여기에만 있다
  js/config.js          상수, 음성 지도(AUDIO)를 데이터에서 만든다
  js/icons.js           아이콘 모음
  js/store.js           기록 저장(localStorage 키 trip-english-v1), 날짜
  js/audio.js           음성 재생, 음성 인식, 효과음
  js/engine.js          채점, 스탬프·배지·레벨, 일차 계획, 학습 진행
  js/ui.js              모든 화면과 앱 설치 안내
  js/main.js            누르기 처리, 시작
  audio/                문장별 mp3 (a1.mp3 … , air-s1.mp3, air-end.mp3 …)
  icons/                앱 아이콘
  tools/make-precache.js   저장 목록·버전 만들기
  tools/make-voices.js     새 문장의 음성 만들기(내 PC에서 실행)
```
**파일을 고치면 `node tools/make-precache.js`를 꼭 다시 실행한다.** 안 하면 사용자 기기에 옛 버전이 남는다.

## 5. 핵심 규칙 (바꾸지 말 것)
1. **문장은 `data/*.js`에만 둔다.** 화면 코드에 문장을 적지 않는다. 새 묶음은 `data/`에 새 파일(`(window.PACKS = window.PACKS || []).push(...)` 모양) + `index.html`에 script 한 줄이면 된다. `config.js`가 `PACKS` 전체에서 음성 지도를 만든다.
2. 한 문장 = `id`, `en`, `ko`, `tip`(원어민 팁), `alt`(이렇게도 말해요), `audio`. 상황극 직원 말 = `s`, `sk`, `sa`.
3. 일차 계산은 `engine.js`의 `dayPlan(D)` 하나로만 한다. `PER_DAY=5`, `WEEK=7`, `GOAL_SEC=10`.
4. 힌트 단계: 1단계 단어 첫 글자(`I'_ l___`), 2단계 앞 두 단어, 3단계 없음.
5. XP: 복습 2, 듣기 3, 따라 말하기 5, 영어로 말하기 맞힘 10(+10초 안 5), 하루 완료 20. 100 XP = 1레벨.
6. 스탬프: 장면 문장을 모두 배우면 받는다. 배지 6종은 `engine.js`의 `achievements()`.
7. 말투: 짧은 문장, 쉬운 말, 존댓말(~요). 오류 메시지는 무슨 일인지와 해결 방법을 쓴다.
8. 접근성: 누르는 곳 44px 이상, 키보드 포커스 표시, 움직임 줄이기 설정 존중, 글자·배경 대비 확보.

## 6. 다음에 할 일 (순서대로)
1. **실기기 확인(Sonnet 아님, 사람이 한다).** 안드로이드 크롬과 아이폰 사파리에서 열어 확인: 소리가 나는가, 마이크 허가가 뜨는가, 음성 인식이 되는가(안 되면 "스스로 판단"으로 넘어가는가), 홈 화면에 추가가 되는가, 비행기 모드에서 열리는가.
2. **배포(무료).** 정적 파일이라 어디든 올릴 수 있다. GitHub Pages가 가장 쉽다. 올린 뒤 `https` 주소로 1번을 다시 확인.
3. **일상 대화 묶음(Opus).** 장면 3~4개 × 10문장. 문장 기준은 7절. 끝나면 `tools/make-voices.js`로 음성을 만들고 `data/daily.js`로 추가.
4. 글꼴을 앱 안에 넣기(지금은 구글 글꼴을 인터넷에서 받는다. 오프라인 첫 방문에서는 기본 글꼴로 보인다).
5. 내 녹음 다시 듣기(`MediaRecorder`)를 실기기에서 시험하고 켤지 정한다.
6. 사용자 반응을 본 뒤: 판매 방식, 로그인·기록 보관, 스토어 앱 포장.
7. 2단계: AI 대화 상대(`AI_PARTNER`, 지금은 꺼짐).

## 7. 문장을 쓰는 기준 (Opus)
- 실제 여행·일상에서 **원어민이 먼저 꺼내는 말**만 쓴다. 교과서식 문장은 뺀다.
- 한 문장은 1~8단어, 한 번에 소리 내어 말할 수 있는 길이.
- 한국어는 구어체(~예요, ~할게요). 영어와 뜻이 정확히 맞아야 한다.
- 팁은 1~2문장: 쓰는 상황, 비슷한 말, 흔한 실수 중 하나만.
- 같은 틀을 바꿔 쓰는 문장을 묶는다(Can I ~? / I'd like ~).
- **쓴 문장은 검수를 거친다**: 부자연스럽거나 뜻이 틀린 곳이 있는지 Opus가 한 번 더 읽고, 의심되는 문장은 "확인 필요"로 표시한다.

## 8. 합격 기준
**기능**
- [ ] 1일차부터 7일차까지 순서대로 진행된다 (확인함: 컴퓨터 크롬)
- [ ] 2~6일차는 전날 문장 복습 뒤 새 문장이 나온다 (확인함)
- [ ] 7일차는 그 주 문장 전체 복습이다 (확인함)
- [ ] 음성 인식이 안 되는 기기에서 "스스로 판단"으로 끝까지 된다 (확인함: 시늉으로. 실기기 미확인)
- [ ] 인터넷 없이 열리고 소리가 난다 (확인함: 컴퓨터 크롬)
- [ ] 기록이 닫았다 열어도 남는다 (확인 필요: 실기기)
**효과** ★
- [ ] ★ 쓰기 시작한 지 4주 뒤, 한국어만 보고 30문장을 10초 안에 영어로 말한다 (사용자 확인 필요)
**쓰기 쉬움**
- [ ] 처음 여는 사람이 설명 없이 1일차를 시작할 수 있다 (사용자 확인 필요)
- [ ] 한 번에 5~10분이면 끝난다 (확인 필요: 실제 시간 재기)
**성취감**
- [ ] 하루를 끝내면 축하 화면과 XP가 나오고, 장면을 끝내면 스탬프를 받는다 (확인함)
**상품 준비(지금 단계에서는 보류)**
- [ ] 음성 약관, 이름 상표, 개인정보 안내문 (6절 6번 이후)

## 10. 지시 방법 (Claude Code에 넣는 첫 문장 예)
> `passport-english/` 폴더와 `docs/제작지시서.md`를 읽고, 6절 3번(일상 대화 묶음)을 Opus로 설계·작성해 `data/daily.js`를 만들어 줘. 7절 기준을 지키고, 의심되는 문장은 "확인 필요"로 표시해 줘. 끝나면 `node tools/make-precache.js`를 실행해 줘.
